**Como instalar no Android:** baixe o APK no celular, toque nele e permita "instalar apps desconhecidos" para o navegador ou o gerenciador de arquivos.

- Anúncios, compras e analytics estão em **modo simulado**, marcados como "modo de teste". Nenhuma cobrança real é feita.
- Android 7.0 ou superior (API 24+), com suporte a ARM64 e ARMv7.
