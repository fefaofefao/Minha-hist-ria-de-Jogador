# Minha História de Jogador ⚽

Jogo para Android de **carreira de jogador de futebol**: começa na final do campeonato do bairro e, dependendo do seu desempenho, você vai para a base de um clube grande ou de um clube médio. Daí em diante, cada lance e cada decisão escrevem a sua história.

- **Plataforma:** Android (Google Play)
- **Modelo:** gratuito, com anúncios e compras no app
- **Status:** fase de ideias e design
